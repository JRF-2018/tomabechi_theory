# 追加の明示条件（Additional Assumptions）について

このプロジェクトの主結果は、**論文（原文）の前提に、ここに書く「追加の明示条件」を加えた条件下で**、四法印13定理（1–4・16・19–26）、定理23に必要な補助の定理15(I)、別論文の定理27の対象結論を Lean 4 / Mathlib で証明した、というものです。
この文書は、その「追加の明示条件」が何で、なぜ必要になり、何を意味しないかを説明します。

## 1. なぜ追加の条件が要るのか

原文の定理は、証明に必要な前提を**すべて**書いているとは限りません。たとえば次のような点です。

* 滑らかさ・可測性・可積分性・軌道の存在などの**正則性**が、定理の主張の中で暗黙に使われている。
* 「各時刻の状態」「到達できる集合」「残差」が、**同じ軌道から**来るのか別々に選ぶのかが書かれていない。
* 可算無限個の層の和を項別に微分してよい条件は、原文でも版によって異なる形で与えられている。

Lean は、これらを一つ一つ**型として**書かないと定理を述べられません。そこで次の方針をとりました。

* 原文が**独立に置いている条件**（定理15のA7、定理23-A、24-A、25-D、26-A、27-A、定理16の条件付き縮小性など）は、「追加」には**数えません**。
* **証明したい結論そのもの**（指数収束、情報達成、固定点の存在、無明と行の同値など）を追加条件にしません。
* 追加するのは、正則性・可測性・可積分性・不変性・データの整合といった、**型として具体的に書ける十分条件**だけです。強い条件を選んだときは、成り立つ範囲を明示します。

定理27の空間は、原文が $X_\top\subset\mathbb R^n$、$U\subset\mathbb R^m$ と明記しているので、有限次元ユークリッド空間をそのまま使っています。これは追加条件には数えません。

### 条件の強さについての注意

H-flow、H-sum、H-stage は、**数学的に必要だと証明した条件ではありません**。現在の証明を確実に適用するための**十分条件**です。Lean 側の実装の都合と、原文そのものの論理的な不足は区別して考えています。
とくに H-flow は、定理20の入口で「全時刻・全ambient点での通常の微分可能性」を要求しますが、これは原文の前向き Carathéodory 解（絶対連続かつ a.e. で ODE を満たす）より強い条件です。

## 3. 何が言えたか

### 3.1 追加条件を許した場合の完成

論文の前提に、上の追加の明示条件を加えた条件下で、対象結論の**一般の量化と定量的な結論を保ったまま**証明できました。Codex（GPT-6.1-Sol）による独立再監査（2026-10-01）でも、原文の前提・Lean の型・結論・条件の対応を照合し、条件付きの一般証明を完了と判定しています。

* 対象は、四法印13定理（1–4・16・19–26）、補助の定理15(I)、別論文の定理27。
* `lake build Tomabechi` が成功し、主要な宣言の公理は標準公理（`propext`・`Classical.choice`・`Quot.sound`）のみ、`sorry` はありません。

### 3.2 原文の前提だけでは成り立たない例がある

**定理19（自由意思定理）の情報達成節**には、次の反例があります。

* 原文の抽象的な可測条件（有限離散ゴール、可測な決定論的方策、入力ほとんど至る所での単射性）**だけ**から、「情報達成 $I(G;Y\mid X)=H(G\mid X)$」は**出ません**。
* 出力空間 $Y$ に可測構造の制約を置かないと、可測で単射な方策でも、観測できる法則では**条件付き相互情報量が 0**（ゴールの情報が一切見えない）になる具体例を構成しました（自明な $\sigma$ 代数を持つ出力）。ゴールのエントロピーは $\log2>0$ なので、$0<\log 2$ の厳密な不等式です。
* 該当する Lean：`Theorem19_Counterexample.lean`（`P16_exists_concrete_counterexample_under_measurable_output_reading`）。

これは**原文が出力の可測構造を指定していないこと**に由来します。標準 Borel 空間のような通常の正則な出力空間（H-info）では成り立つので、原文の定理そのものや物理的な制御出力としての解釈を否定するものではありません。**原文の前提のみからは導けない定理が存在する**、という意味です。

### 3.3 追加条件を含めた無矛盾性

原文の前提と、上の追加の明示条件を、**同時に満たす非退化なモデル**を Lean で構成しました（Lean／Mathlib の基礎に相対的）。条件の名前（`ExplicitHInfo`・`ExplicitHFlow`・`ExplicitHSum`・`ExplicitHStage`）は `Tomabechi/Consistency/ConsistencyR123_HConditions.lean` にあります。構成の見取り図は [Consistency_Overview.md](Consistency_Overview.md)、原文の前提との対応は [Consistency_Premises_Table.md](Consistency_Premises_Table.md) を見てください。H-flow には、状態の距離・制御の位相が原文のノルム／Borel 構造と一致することも含めています（H-flow″）。

### 3.4 追加条件は絶対に必要なわけではない

はじめに提示した追加条件のいくつかは、**緩和しても成り立つ**ことを示しました。

* **H-stage の緩和：** もとの H-stage は「初期値で決まる全部分準位集合の閉包が開球に入る」ことを要求していました。緩和した入力は、**球の内側にある、より小さな前向き不変領域**だけを要求します。1次元モデル（`Theorem22_InvariantRegion_Model.lean`）で、**もとの入力は成り立たない**（全部分準位が球の外へ出る。`toy_old_sublevel_barrier_fails`）が、**緩和した入力からは、初期値の一致と率 1 の指数減衰が成り立つ**ことを証明しました。
* 緩和した平均場の段階は、定理21の谷・変位・指数軌道の結論と、同じ生成データからの KL 型の条件付き相互情報量への接続を保ちます。

したがって、追加条件は「これでなければ証明できない」必然の条件ではなく、**現在の証明が使っている十分条件**です。

## 4. この結果が主張しないこと

* **原文の前提のみからの導出ではありません。** 上の追加条件を加えた条件付きの結果です。
* **追加条件を満たす数学的モデルは構成しました**（[Consistency_Overview.md](Consistency_Overview.md)）。ただし、定理16の正典 TCZ を生成する制御系は層別に置いたもので、定理24の制御系とは別です。単一の共有制御系で原文全体を実現したという主張ではありません。また現実の認知モデルでもありません。
* **照合した原文は 2026-09-30 に取得した掲載版**です。公開初日の版と同一であることは確認していません。
* **物理的・思想的な妥当性は主張しません。** 仏教語（空・涅槃・無明・行など）は、各論文の数理体系の内部で定義された概念として扱い、形式化された数理結論と同一視しません。
* **定理20**では、前向き Carathéodory 解から現在の H-flow の条件（全時刻・全ambient点の通常微分）を導く一般化が未完です。
